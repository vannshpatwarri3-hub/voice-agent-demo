# AI Voice Agent — live demo

A Hinglish-speaking voice agent that answers pre-calls, establishes who is calling and what
they need, and then hands off.

**▶ Try it live:** https://vannshpatwarri3-hub.github.io/voice-agent-demo/

Click **Talk to Atoms** in the bottom-right corner, press **Start**, allow microphone access,
and speak to it.

---

## How it opens

> "Namaste. Main Vannsh Patwarri ka personal assistent hun.
> Kya main jaan sakta hun ki aap kon baat kar rahain hai?"

## Stack

| | |
|---|---|
| Platform | Atoms (Smallest AI) |
| Voice infrastructure | LiveKit Cloud |
| Mode | Real-time voice |
| Language | Conversational Hinglish |
